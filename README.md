# E-Commerce Website Frontend

A simple, clean, and responsive **frontend** for an e-commerce website. This project provides a basic shopping interface, product catalog, and cart functionality ready to be hooked to a backend API.

---

## Technologies Used

- **HTML5** — for structuring the web pages  
- **CSS3** — for styling, layout, and responsive design  
- **JavaScript (ES6)** — for interactivity and DOM manipulation  

---

## Features

- Responsive UI (works on desktop, tablet, mobile)  
- Product catalog (listing products, showing images, names, prices)  
- Shopping cart: add items, remove items, update quantities  
- Cart summary display (subtotal, item count)  
- Basic UI for checkout (placeholder — requires backend integration)
